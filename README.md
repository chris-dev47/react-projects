# React Projects

Application web React regroupant une interface d'accueil, une présentation des projets et une page de contact. Ce dépôt sert de base de travail et de démonstration pour des réalisations front-end.

## Fonctionnalités présentes

- Navigation entre Accueil, Projets et Contact.
- Routage côté client avec React Router.
- Interface organisée en pages et composants.
- Configuration de scripts de développement, de test et de build.

## Stack technique

- React
- JavaScript
- React Router
- Create React App

## Prérequis

- Node.js (version LTS recommandée)
- npm

## Installation

```bash
git clone https://github.com/chris-dev47/react-projects.git
cd react-projects
npm install
npm start
```

L'application démarre par défaut sur [http://localhost:3000](http://localhost:3000).

## Commandes disponibles

| Commande | Utilité |
|---|---|
| `npm start` | Démarrer le serveur de développement |
| `npm test` | Lancer les tests |
| `npm run build` | Générer la version de production |

Le dépôt contient actuellement une structure React avec trois pages et une navigation. Les tests, le rendu responsive, l'accessibilité et le déploiement restent à vérifier avant de le présenter comme une application prête pour la production.
